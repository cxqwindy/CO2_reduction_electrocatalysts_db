# synthesis_paragraph_classifier

A runnable reproduction of the paragraph-classification stage described in *Large language model enhanced corpus of CO2 reduction electrocatalysts and synthesis procedures*.

The implementation retains the cited method's core settings: sentence-level LDA (200 topics, priors `alpha=5/N`, `beta=0.01`), topic-probability threshold 0.05, adjacent-sentence topic 1–3 grams, and a random forest with 20 trees and maximum depth 20. The original 760 annotated paragraphs and 12,643-paper LDA corpus are not present in this directory and are distribution-restricted. Therefore, this repository deterministically reconstructs 228 positive and 532 negative weakly labelled examples from local `gold_data` and trains LDA on that local corpus.

```bash
python -m pip install -e .
python -m synthesis_paragraph_classifier generate-data
python -m synthesis_paragraph_classifier train
python -m synthesis_paragraph_classifier predict "Cu nitrate was dissolved in water, heated, washed and dried."
python -m synthesis_paragraph_classifier topics 0
```

This repository snapshot includes the 532 reconstructed negative examples and both trained model artifacts. The positive examples and combined training file can be regenerated with `generate-data` when the source `gold_data` directory is available.

Bundled artifacts:

- `data/negative_examples.jsonl`: exactly 532 negative examples
- `models/lda_model.joblib`: trained sentence LDA model
- `models/paragraph_classifier.joblib`: complete trained LDA + feature extractor + RF classifier
- `models/model_metadata.json`: reproducibility configuration and dimensions

Generated by `generate-data`:

- `data/positive_examples.jsonl`: 228 reconstructed positive examples
- `data/paragraph_classification_training_data.jsonl`: combined 760 examples

Python API:

```python
from synthesis_paragraph_classifier import get_default_model

model = get_default_model()
label, confidence, details = model.classify_paragraph("The powder was calcined at 500 °C for 2 h.")
```
